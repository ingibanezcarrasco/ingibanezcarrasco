# Hola, soy Iván 👋

Ingeniero de calidad y automatización en el sector automotriz (IATF 16949 / ISO 9001).
Construyo herramientas que convierten la evidencia del proceso en algo que se
puede revisar, medir y auditar: auditorias de registros, tableros de indicadores,
RCA con causa raiz,PDP yScorecards.

Me gusta el trabajo de campo tanto como el codigo: lo que sale de la linea de
produccion tiene que llegar al expediente de auditoria con la misma informacion
que se genero.
