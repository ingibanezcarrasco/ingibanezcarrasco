# Hola, soy Iván 👋

Ingeniero de calidad y automatización en el sector automotriz (IATF 16949 / ISO 9001).
Construyo herramientas que convierten la evidencia del proceso en algo que se
puede revisar, medir y auditar: auditorias de registros, tableros de indicadores,
RCA con causa raíz, PDP y scorecards.

**Desarrollo mis propias herramientas, asistido por IA.** Uso Claude Code para
escribir código y modelos locales (Ollama) para lo que no puede salir de la
máquina, con reglas que no negocio: cero datos de cliente en los repositorios,
todo corre en local, y la IA propone mientras el auditor decide. Casi todo lo
que publico aquí lo construí porque en mi propio trabajo faltaba una
herramienta.

Me gusta el trabajo de campo tanto como el código: lo que sale de la línea de
producción tiene que llegar al expediente de auditoría con la misma información
que se generó.

Últimamente me interesa una cosa: **que los agentes de IA entiendan la norma**.
Los modelos escriben bien, pero no saben qué exige una cláusula ni cómo se
llena una tabla de prioridad de acción; `mcp-calidad` se lo da, con la referencia
normativa, el criterio de cierre y en seis idiomas.

## 🤖 Cómo desarrollo

- **IA como copiloto de código**: Claude Code para escribir, refactorizar y
  probar; modelos locales vía Ollama para lo que no puede salir de la máquina.
- **IA dentro del producto**: el servidor MCP de PDCAhub Calidad le da a
  cualquier agente las reglas ISO 9001 / IATF 16949, el 8D y el plan de control
  en seis idiomas, para que no improvise la norma.
- **Regla que no se negocia**: la IA propone, el auditor decide. Cada
  hallazgo, cada cita normativa y cada prueba se revisan a mano.
- **Privacidad por diseño**: las herramientas corren local y ningún dato de
  cliente entra a un repositorio ni sale de la máquina del cliente.
